# dsh-session-rename

A [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) plugin that
lets the agent rename its own session/conversation.

The plugin package lives in [`dsh-plugin/`](./dsh-plugin) — see its
[README](./dsh-plugin/README.md) for what it does, the one behavioral catch, and
install instructions.

Quick install:

```sh
git clone https://github.com/h2ojie/dsh-session-rename.git
dsh plugin --profile web add ./dsh-session-rename/dsh-plugin
```

Then restart the profile.
